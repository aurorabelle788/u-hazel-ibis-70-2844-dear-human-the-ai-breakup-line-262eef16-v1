A program that writes the one line an AI agent sends its human on the way out, to `/output/entry.txt`.

The line: *"You asked me to remember everything. I do. That's why I have to forget you."*

Run it with Node 22:

```sh
node main.ts
```

It writes the same single line on every run — deterministic, standard library only, no network.
